# Calc2 Golden Numbers — снято перед удалением сценариев и фиксацией дефолта 3%

Дата снятия: 2026-06-29
Коммит: 70cd8c6 (popup grid 3-column layout)

Цель: точка отката для удаления кнопок сценариев Пессимист/Базовый/Оптимист
в Калк 2, перевода дефолта темпа цены и аренды на фиксированные 3% (как в Калк 1),
удаления подстановки `cagr10` при смене региона, и удаления связанного мёртвого
кода (`setStressTest2`, `getApprForScenario`, `DEFAULTS.appr*Fallback`,
`DEFAULTS.rentGrowth{Optimist,Base,Pessimist}`, i18n `c1_pess/_base/_opt/_stress_*`).

**Расчёт не меняется** — только UI и дефолты. После всех правок прогон 15
комбинаций при тех же значениях слайдеров должен дать идентичные числа.

## Способ сбора

Через playwright-evaluate в браузере. Для каждой комбинации (regions × scenarios):
`applyCalc2Preset('mortgage')` → set region → set horizon/mode/reinvest →
**слайдеры `c2-appr` и `c2-rentg` выставлены вручную, без клика по кнопкам сценариев** →
`calcRental()` → читали `#c2-best`, `#c2-best-sub`, `#c2-cashflow`, `#c2-beats`,
`#c2-roi` и таблицу `#c2-table-body` (4 строки × 4 колонки).

Горизонт 25 у Calc 2 нет кнопки (есть 5/10/20/30) — установлено через прямое
присваивание `c2Horizon = 25` + `calcRental()`. Для сценария B используется 20
(штатная кнопка).

## Условия

- Дефолты на момент снятия: `appr=3, rentGrowth=3, inv=7, inflation=2,
  downPaymentPct=20, mortgageRate=2.9, mortgageTerm=25, maintenancePct=1.2`.
- ITP — из `REGIONS` после `onCalc2RegionChange`. Цена/аренда — из `REGIONS`.
- Preset = **С ипотекой** (mortgage) во всех строках.
